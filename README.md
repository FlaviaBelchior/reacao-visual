# ReAção Visual

Plataforma educacional bilíngue e visual para ensino de reações químicas a estudantes surdos.

## Stack
React + TypeScript + Vite + Supabase + PostHog + Vercel.

## Princípios
Libras + português escrito desde a arquitetura; Pedagogia Visual; DUA; interação; acessibilidade; segurança experimental.

## Desenvolvimento
```bash
npm install
npm run dev
npm run build
```

Variáveis necessárias estão em `.env.example`.
